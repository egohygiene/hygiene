# ADR-000: Replace with a concise decision title

> Copy this normative reference into
> `docs/decisions/ADR-NNN-short-slug.md`. New records always begin as
> `proposed`. Remove this note from the copied record.

## Context

Describe the forces, constraints, current evidence, and durable boundary that
make a decision necessary. Distinguish known facts from assumptions.

## Decision

State one specific proposed choice. Explain its scope and the authority it does
and does not grant.

## Alternatives considered and rejected

List only alternatives that were actually considered. Give the reason each was
not selected. Do not fabricate alternatives for completeness.

## Consequences and tradeoffs

Describe benefits, costs, risks, compatibility obligations, and changes that
become required or prohibited.

## Implementation and evidence links

Link the issue, pull request, commits, releases, validation runs, evaluations,
or external standards that exist. State evidence gaps explicitly. Do not claim
planned validation as completed evidence.

## Replacement or exit strategy

Explain how the dependency, format, platform, or boundary can be replaced or
retired and what compatibility or migration work that would require.

## Follow-up work

List linked follow-up issues or state that none are known. Keep task detail in
the issue tracker rather than reproducing a backlog here.
